How the queue is ordered

  1. Priority. Emergency vehicles go first, then high, then normal.
  2. Battery level. Within the same priority, the lower battery is served first.
  3. Arrival time. If both match, the vehicle that arrived earlier is served first.
  4. Waiting time is the time a slot is allocated minus the arrival time.
